# Інструмент порівняльного аналізу роману «Тигролови»

**Розробка вебінструменту порівняльного аналізу оригінального та адаптованого художнього тексту (для рівнів B1–B2)**

🔗 **[Відкрити вебінструмент](https://yevheniia047.github.io/tyhr-lovy_adaptation/)**

---

## Про проєкт

Цей репозиторій містить інтерактивний вебінструмент, розроблений у рамках бакалаврської роботи з лінгводидактики. Інструмент реалізує цифрове середовище для порівняльного аналізу оригінальних уривків з роману Івана Багряного «Тигролови» та їх адаптації для іноземних читачів рівнів B1–B2 (адаптатори: Ірина Багмут та Вікторія Штефуца, 2011).

Мета — не просто зіставити два тексти, а унаочнити лінгвістичну механіку адаптації: класифікувати кожну трансформацію, зафіксувати вилучену лексику та образні засоби, надати дослідникові та студентові інструмент для самостійного дослідження.

## Функціональні модулі

### 🔍 Порівняльне зіставлення текстів
Паралельне відображення оригіналу та адаптації у двох синхронізованих колонках. Кожен запис позначено кольором залежно від типу трансформації:

| Колір | Тип |
|---|---|
| без підсвічування | без змін (код 0) |
| рожевий | вилучення (код 1) |
| жовтий | заміна (код 2) |
| фіолетовий | комбінована зміна (код 3) |

При наведенні на змінений запис з'являється тултіп із лінгвістичним коментарем.

### 📚 Словник вилучених словоформ
191 лексична одиниця, класифікована за вісьмома типами: архаїзми, діалектизми, історизми, розмовна лексика, лексика зі складною граматичною структурою, поетизми, специфічна та іншомовна лексика. Фільтрація за частиною мови та текстовий пошук.

### 💬 Тропи та фразеологізми
41 стилістично маркована одиниця з оригіналу: тропи, фразеологізми, образні конструкції. Для кожної — стратегія адаптації (вилучено / змінено) та лінгвістичне обґрунтування.

### 📊 Статистична панель
Кількість слів і речень, розподіл трансформацій за типами з відсотковими показниками, коефіцієнт стиснення тексту.

### 📝 Лексичний тест
100 питань на основі словника. При кожному запуску випадково обирається 12 питань. Після відповіді відображається розгорнутий лінгвістичний коментар.

## Як використовувати

1. Відкрийте [вебінструмент](https://yevheniia047.github.io/tyhr-lovy_adaptation/) у браузері
2. Оберіть уривок — «Родина Тигроловів» або «Світ на колесах»
3. Перегляньте вкладки: **Порівняння**, **Словник**, **Тропи та фразеологізми**
4. Використовуйте фільтри та пошук для вибіркового аналізу
5. Пройдіть лексичний тест для самоперевірки
